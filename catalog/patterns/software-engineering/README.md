# Software Engineering Patterns

이 디렉터리는 agentic development에서 **software와 repository를 설계·구현·검증·운영하는 문제**를 다루는 reusable pattern을 보관합니다.

대표적인 범위는 다음과 같습니다.

- repository와 code organization
- architecture와 implementation boundary
- testing, migration, reliability와 operability
- 유지보수성과 개발자 navigation을 포함한 engineering structure

Agent/harness의 context mechanics는 [`context-engineering/`](../context-engineering/), durable 기술 문서 구조는 [`documentation/`](../documentation/), 작업 lifecycle은 [`workflow/`](../workflow/)이 소유합니다.

Pattern은 primary problem이 software engineering일 때 이 directory에 둡니다.
