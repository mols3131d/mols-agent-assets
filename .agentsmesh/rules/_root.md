# Repository Contract

## Authority

- `.agentsmesh/` is the canonical source for portable coding-agent Rules and Skills managed by AgentsMesh.
- `agentsmesh.yaml` selects active coding-agent targets and features.
- Harness-native files generated by AgentsMesh are derived artifacts. Edit the canonical `.agentsmesh/` source instead of hand-editing generated output.
- `src/skills-chatbot/`, `src/skills-chatbot-runtime/`, and `src/prompts/` remain separate hosted-chatbot or prompt profiles unless explicitly migrated later.
- `tests/` owns repository-level automated verification; package-local evals remain with their package when their lifecycle is package-specific.
- `docs/` owns human-facing standards, references, and migration records.

## Language

- Use natural Korean for user-facing prose by default. Keep established IT terms in English or parallel when that is clearer or more precise.

## Asset Doctrine

- Primary Agent Asset types are Rule, Skill, Prompt, and Agent. Supporting resources are not peer asset types.
- Prefer one authoritative owner per durable behavior or policy.
- Prefer Skill for reusable capabilities or situation-specific context that should load on demand rather than globally.
- Preserve target-specific behavior only when the target actually supports it; do not claim semantic parity from format conversion alone.
- Do not add wrapper compilers, parallel canonical schemas, or adapters around AgentsMesh without a concrete repeated limitation.

## Development

- Follow repository branch, commit, PR, and validation rules in `docs/development.md` and applicable repository instructions.
- Do not commit ordinary change work directly to `main`.
- Keep generated configuration and canonical source reviewable in the same change when generation is part of the change.
- Use the smallest relevant validation. For AgentsMesh-managed assets, include `agentsmesh lint` and drift/regeneration checks when executable.
- Do not claim runtime behavioral parity, trigger quality, or target execution success without runtime evidence.
