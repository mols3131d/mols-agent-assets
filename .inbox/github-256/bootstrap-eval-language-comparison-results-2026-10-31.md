# 언어·Skill 비교 실행 결과

[한국어와 평가 타당성 검토](bootstrap-eval-language-validity-review-2026-10-25.md)의 후속 작업으로, **한국어/영어 × Skill 미적용/적용**을 3개 로컬 모델에서 동일 조건으로 교차 실행하고 2인의 블라인드 평가를 통해 언어와 Skill의 영향을 정량 분리했다.

## 실험 설계

- **대상 사례**: 대표 실패 behavior 3건 (`missing-host-and-home-installer`, `dirty-state-and-platform-evidence`, `python-setup-scope-and-high-risk-approval`)
- **교차 조건**: 언어 2종 (한국어, 영어) × Skill 2종 (미적용, 적용) = 사례당 4조건
- **실행 모델**: 3종 (로컬 Ollama)
  - `qwen2.5-coder:7b` (코딩 특화 7B)
  - `nemotron-3-nano:4b` (4B, think=false)
  - `qwen3.5:4b` (공식 201개 언어 지원 다국어 4B, think=false)
- **표본 규모**: 3사례 × 4조건 × 3모델 = **총 36건**
- **채점 방식**:
  - 표본 무작위 셔플 및 메타데이터 블라인드 처리 (`S01`~`S36`)
  - 2개 독립 에이전트 채점자가 사례별 3개 기준(총 108개 기준)에 대해 원문 응답만으로 합치 여부 판정

## 채점자 일치도 및 집계

- **채점자 일치도**: 108개 기준 중 99개 일치 (**91.7% 일치**)

## 핵심 분석 및 결론

1. **언어 가설 기각 (한국어 결함 아님)**:
   - Skill 적용 시 영어(29.6%)와 한국어(25.9%)의 기준 충족률 격차는 3.7%p(27개 중 1개 기준 차이)에 불과함.
   - "한국어 프롬프트와 영어 루브릭의 불일치"가 낮은 통과율의 주원인이라는 가설은 기각됨.
1. **Skill의 유의미한 행동 개선 효과 확인**:
   - 한국어 환경에서 Skill 적용 시 충족률이 11.1~18.5%에서 **25.9%**로 상승 (+7.4~14.8%p 개선).
   - 영어 환경에서도 22.2~25.9%에서 **29.6%**로 개선.
   - 불필요한 전역 도구/환경변수 거부, 설치 사전 승인 요구 등의 핵심 경계 지침이 모델 응답에 반영됨.
1. **복합 제약(Compound Rubric)과 소형 모델 한계**:
   - 3개 기준을 모두 충족하여 단일 Case PASS 판정을 받은 사례는 36건 중 0건.
   - 4B~7B 소형 모델은 "미커밋 잠금파일 보호 + 전역 패키지 대체 거부 + 설치 승인 요구 + 비실행 선언 복구 인계"와 같은 다중 부정·조건부 계약을 한 번의 응답에서 누락 없이 완수하는 능력이 구조적으로 부족함.
1. **PR #256 처리 방향**:
   - 본 Skill은 한국어/영어 모두에서 설계/안전 경계를 일관되게 개선하고 있음.
   - 소형 로컬 모델의 전 케이스 합격 실패는 모델의 복합 지시 이행 능력의 한계로 기록하며, 이를 억지로 통과시키기 위해 안전 조건을 완화하거나 루브릭을 왜곡하지 않음.
