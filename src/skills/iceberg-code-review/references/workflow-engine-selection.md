description:
---

1. Engine specified -> use it.
2. No engine, purpose given -> apply relevant external skill/instructions; none -> matching built-in engine.
3. No engine, no purpose -> default `implementation` + `quality`.
4. New review area mid-review -> no engine addition. Recommend follow-up in report.
5. Duplicate details across engines -> merge; keep higher `priority`.
