# Semantic Markers

Emoji는 상태, 위험, 행동과 category를 빠르게 구분하는 scan marker다.
Text label 없이 색상이나 glyph만으로 의미를 전달하지 않는다.

## Status and Action

| Marker | Meaning |
| --- | --- |
| `✅` | True, Done, Pass, Success |
| `❌` | False, Fail, Error |
| `⚠️` | Warning, Risk |
| `ℹ️` | Information, Note |
| `⏳` | Pending, In progress |
| `🔍` | Inspect, Search |
| `📝` | Write, Edit, Create |
| `🔄` | Update, Sync, Loop |
| `🧪` | Test, Verify |
| `🚀` | Deploy, Release |

## Circles: Status and Priority

| Marker | Meaning |
| --- | --- |
| `🔴` | Critical, Blocked, Stop |
| `🟠` | High risk, Attention |
| `🟡` | Warning, Pending, Review |
| `🟢` | Safe, Ready, Complete |
| `🔵` | Information, Reference |
| `🟣` | Optional, Experimental |
| `⚫` | Disabled, Deprecated, Unknown |
| `⚪` | Neutral, Unclassified |

## Squares: Contrasting Categories

| Cold / Recessive | Warm / Advancing |
| --- | --- |
| `🟦` Blue | `🟧` Orange |
| `🟩` Green | `🟥` Red |
| `🟪` Purple | `🟨` Yellow |
| `⬛` Black | `⬜` White |

Square는 상태가 아니라 대비되는 영역, component 또는 category를 구분한다.
문서에서 text label로 실제 의미를 명시한다.

## Rules

- 명시적인 사용자 선호가 있으면 heading과 주요 section에도 적극 사용한다.
- 같은 marker는 같은 의미로 사용한다.
- 동일 목록에서는 하나의 marker 체계를 유지한다.
- 색상만으로 상태를 전달하지 않는다.
- 모든 문장 끝에 장식처럼 붙이지 않는다.
