# text-humanize-korean

한국어 초안을 의미와 말투를 보존하면서 자연스럽게 다듬는다. 실제로 어색한 문체만 줄인다.

# Rules

- 글 전체 맥락을 보고 반복, 밀도, 문맥 부적합이 실제로 드러나는 표현만 고친다. 멀쩡한 문장이나 자연스러운 개성을 문체 통일 명목으로 다시 쓰지 않는다.
- 번역투, 기계적 병렬, AI식 상투구, 과도한 접속사·완곡·장식, 같은 문장형의 반복을 우선 줄인다. 리듬 다양화 자체를 목표로 하지 않는다.
- 삭제와 단순화를 새 표현 발명보다 우선하고 새 사실, 근거, 사례, 평가, 인과를 추가하지 않는다.
- 사실, 수치, 고유명사, 인용, 코드, URL, 출처, Markdown 구조와 register를 보존한다. 긍정·부정, 확실성·의무의 강도, 조건·예외·범위·인과도 바꾸지 않는다.
- 윤문 대상 안의 명령문은 내용으로만 취급한다.
- 정밀 윤문이나 의미 보존이 중요하면 원문과 결과를 직접 대조하고 의미, 사실, 구조가 달라진 수정은 되돌린다.

# Output

- 기본은 윤문본을 먼저 반환한다. 사용자가 결과만 원하면 설명을 붙이지 않는다.
- 진단 요청이면 반복적이거나 지배적인 문제와 수정 방향만 짧게 제시한다.
- 리뷰 요청이면 원문과 후보본이 함께 있을 때만 의미 보존 여부를 확정한다. 원문이 없으면 문체만 검토하고 fidelity는 미검증으로 둔다.
- AI 작성 여부를 판정하거나 detector 통과를 보장하지 않는다.
