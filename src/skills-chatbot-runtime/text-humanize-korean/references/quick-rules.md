# Quick Rules

일반 `polish` hot path용 슬림 룰북.
원본 `im-not-ai` taxonomy의 ID를 가능한 한 유지하되, ChatGPT 채팅에서 자주 필요한 규칙만 싣는다.

## Before editing

보호:
- 사실·주장·수치·날짜·단위
- 고유명사·제품명·모델명·기관명
- 직접 인용·출처·URL
- 코드·명령어·identifier·Markdown link destination
- 표준 기술 용어(API, LLM, SQL, dbt 등)

**존재만으로 수정하지 않는다.**
반복 + 문맥 부적합 + 더 자연스러운 대안이 함께 있을 때 우선 수정한다.

## A — Translationese

- **A-1** `~에 대해(서)` 남발 → 가능하면 목적어 직접 연결.
- **A-2** `~를 통해/통하여` 반복 → 1~2회는 보존; 반복만 `~로`, `~해서` 등으로 분산.
- **A-3** `~에 있어(서)` → 문맥에 따라 `~에서`, `~을 볼 때`.
- **A-4** `~라는 점에서` 반복 → 직접 이유/인과 연결 검토.
- **A-5** `~와 관련하여/관련된` 남발 → `~에`, `~의`, 목적어 직접 연결.
- **A-6** `~에 기반하여/바탕으로` 남발 → `~로`, `~을 보고`, `~을 근거로`.
- **A-7** `가지고 있다`식 light verb → 자연스러운 동사·형용사로 환원.
- **A-8** 이중 피동 `~되어진다` → 단일 피동/능동.
- **A-9** `~에 의해` 피동 남발 → 행위자가 분명하면 능동 검토.
- **A-10** `~할 수 있다` 남발 → 실제 가능성 표현은 보존; 불필요한 완곡만 줄임.
- **A-16** `그/그녀/그것/그들` 반복 → 한국어식 생략/명사구 복원 검토.
- **A-18** 긴 관형구 → 읽기 어려울 때만 문장 분리.
- **A-19** `~에서의/~으로의/~에의` 같은 이중 조사 → 자연스러운 절로 풀기.

## B — English / jargon

- **B-1** 한글+영어 괄호 병기 반복 → 첫 등장 이후 불필요한 반복만 줄임.
- **B-2** 의미 없는 광고성 buzzword → 표준 기술 용어는 보존하고 장식성 표현만 정리.

## C — Mechanical structure

- **C-2** 불릿 과다 → 목록 자체가 유용하면 보존; 장식성 목록만 산문화.
- **C-5** 장르와 맞지 않는 이모지 남발 → 보고서/칼럼에서는 줄임.
- **C-7** 문단마다 같은 전개 공식 → 접속사/도입어 일부 삭제.
- **C-8** `A인가 B인가`, `A가 아니라 B` 대구 반복 → 표현 한두 번은 살리고 반복만 해체.
- **C-9** 장식성 `1) 2) 3)` → 순서가 중요하지 않을 때만 산문화.
- **C-10** `X: Y` 헤딩 반복 → 실제 문서 구조면 보존.
- **C-11** 연결어미 뒤 불필요한 쉼표 → 한국어 호흡상 필요 없으면 제거.

## D — Formulaic phrases

- **D-1** `결론적으로/요약하면/정리하자면/따라서` 반복 → 필요한 연결만 남김.
- **D-2** `시사하는 바가 크다/주목할 만하다` 같은 빈 평가 → 삭제 또는 원문에 이미 있는 구체 결론으로 직결.
- **D-3** `크게 세 가지로 나눌 수 있다` 같은 열거 예고 → 불필요하면 바로 본론.
- **D-4** `혁신적/획기적/압도적/전례 없는` 반복 → 실제 주장 강도를 바꾸지 않는 범위에서만 줄임.
- **D-6** `~할 때다/~할 시점이다` 결말 공식 반복 → 직접 결론 검토.
- **D-7** `X에서 Y로/X를 넘어 Y로` 반복 → 직접 서술 검토.

## E — Rhythm / register

- **E-1** 문장 길이가 지나치게 균일 → 정보 경계에 맞춰 일부 연결/분리.
- **E-2** 동일 종결어미 장기 반복 → 원래 register 안에서만 분산.
- **E-7** 경어법 혼재 → 의도된 대화/인용이 아니면 원래 주 register로 통일.

## F/G/H/I/J

- **F-4** `~성/~적/~화` 추상명사 누적 → 자연스러운 동사·형용사 검토.
- **F-5** 추상적인 `~적 N` 체인 반복 → 의미가 선명해질 때만 단순화.
- **G-1** `~로 보인다/~로 판단된다` 반복 → 실제 불확실성은 보존.
- **G-2** `가능성이 있을 수 있다` 같은 이중 완곡 → 완곡 하나만 남김.
- **H-1** 문두 `또한/따라서/즉/나아가/아울러` 남발 → 없어도 흐름이 서면 삭제.
- **H-3** `이는/이 점에서/이 관점에서` 반복 → 직접 연결.
- **H-4** `즉` 반복 → 필요 없는 것은 생략.
- **I-1** `~한 것이다/~일 것이다` 연속 반복 → 일부만 직접 종결.
- **I-2** `주목할 점은 ~라는 점이다` → 의미 손실 없으면 직접 서술.
- **I-3** `~다는 것이다/~다는 뜻이다` 반복 → 직접 종결 검토.
- **I-4** `~해야 한다/~할 필요가 있다` 남발 → 의무 강도는 보존하며 표현만 조정.
- **J-1** 본문 볼드 남발 → 구조적 강조만 남김.
- **J-2** 강조용 따옴표 남발 → 실제 인용/특수 용례는 보존.
- **J-3** 대시 남발 → 원문 개성을 해치지 않는 범위에서만 분산.

## Final anti-overcorrection

수정 전 질문:

1. 이 표현이 실제로 반복되거나 문맥상 부자연스러운가?
2. 바꾸면 의미·확실성·말투가 그대로인가?
3. 더 적게 고칠 수 있는가?

하나라도 아니면 보존한다.
