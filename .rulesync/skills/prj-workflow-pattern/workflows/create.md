# Create Pattern

**When:** 새 패턴을 제안·신설할 때.

1. `catalog/INDEX.tsv`, category README, 관련 capsule을 조사한다. 여러 상황에서 참고·변형할 수 있는 해결 방식인지 판단한다. 일회성 기록, 저장소 강제 규칙, Agent Asset 실행 계약을 패턴으로 만들지 않는다. 기존 원본이 충분하면 [Improve](improve.md)를 사용한다.
2. 새 문서만 소유할 문제와 primary problem을 구분해 category 하나를 선택한다. 작은 패턴은 단일 Markdown으로 시작하고 독립 resource가 필요할 때만 bundle로 확장한다.
3. 독자가 별도 capsule 없이 문제·적합/부적합 조건·핵심 메커니즘·선택지·유의미한 한계를 이해하도록 작성한다. 필수 section, 과잉 리스크·reference 목록이나 특정 도구·형식을 강제하지 않는다.
4. 사실·가정·권고를 구분하고, 샘플과 외부 규약을 패턴의 의무 계약으로 바꾸지 않는다. description은 카탈로그에서 이 문서를 선택할 조건을 드러낸다.
5. [Review](review.md)를 거치고 변경한 원본은 [Validate](validate.md)한다. 탐색·제공의 변경이 있으면 [Publish](publish.md)를 적용한다.

**Result:** 신설 또는 기존 원본 활용의 판단, 정본 경로, 검토·검증 근거.
