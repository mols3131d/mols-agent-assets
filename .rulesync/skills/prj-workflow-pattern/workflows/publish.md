# Publish Pattern

**When:** `catalog/patterns/`에서 패턴을 발견하고 선택할 수 있도록 제공·탐색을 정리할 때. 외부 프로젝트에 실제 설치·채택하는 작업은 아니다.

1. 원본 capsule의 category와 `description`으로 사용자가 문제·적합 조건을 구분할 수 있는지 본다. category README는 책임과 안내만 소유하고 패턴 본문·전체 인벤토리를 복제하지 않는다.
2. 관련 패턴의 탐색에 도움이 될 때만 링크를 추가한다. `catalog/INDEX.tsv`는 원본에서 생성되는 탐색 자료이며, 등재를 설치·사용 또는 정책 도입 근거로 해석하지 않는다.
3. 원본·탐색 문서를 변경했다면 [Validate](validate.md)를 실행하고 저장소 branch·PR 절차에 따라 제안한다. 승인·Merge·외부 배포 권한은 이 흐름이 부여하지 않는다.

**Result:** 탐색 경로, 원본·인덱스 상태, 실제 제공과 외부 소비의 확인 범위.
