# Review Pattern

**When:** 패턴의 재사용성·정확성·분류·독립성·품질을 검토할 때. 단독 리뷰는 **읽기 전용**이다.

1. 현재 문서와 [Patterns Review](../../../../catalog/patterns/README.md#review), 관련 owner를 읽는다.
2. **적합성**(언제 선택하나), **메커니즘**(core/option 구분), **독립성**(capsule만으로 이해 가능한가), **권한**(강제 정책처럼 보이나), **신뢰성**(출처·한계 유효성), **가독성·비용**(문제·조건·선택지의 탐색, 중복된 문장·섹션·샘플, 불필요한 추론 부담)을 점검한다. 문서 구조·표현 판단은 `mols-documentation`의 기준을 따른다.
3. 새로운 독자와 적용자 관점에서 결과를 바꿀 반례를 찾고, 사실·추정·미검증을 구분한다. 형식을 채우기 위한 지적이나 근거 없는 위험은 만들지 않는다.
4. 결함의 구체적 위치·영향·개선 방향을 보고한다. 사용자가 수정도 요청했을 때만 [Improve](improve.md), [Restructure](restructure.md), [Retire](retire.md) 등을 연결한다. 기계적 검사 요청은 [Validate](validate.md)로 분리한다.

**Result:** 중요도에 따른 findings, 보존할 설계, 불확실성·후속 조치. 리뷰만으로 파일 수정·PR 생성·승인을 수행하지 않는다.
