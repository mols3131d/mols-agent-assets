# Retire Pattern

**When:** 기존 패턴을 더 이상 권장하거나 유지하지 않을지 판단할 때. **원본 삭제를 자동으로 수행하지 않는다.**

1. 부정확·대체·적용 범위 축소·단순 노후화를 구분한다. 여전히 유효한 상황이 있다면 수정·범위 조정·보존이 적합할 수 있다.
2. 현재 독자에게 필요한 대안·이관 경로·참조와 남겨야 할 판단 근거를 확인한다. 필요할 때만 간결한 사용 제한·대체 안내를 남긴다. 모든 은퇴에 deprecated stub·archive·상태 파일을 강제하지 않는다.
3. 원본을 수정했다면 [Validate](validate.md)를 적용한다. 별도의 실제 삭제 요청과 대상·영향·권한이 확인된 경우에만 [Delete](delete.md)로 전환한다.

**Result:** 유지·개선·은퇴·삭제 후보의 선택 근거, 남겨둘 안내와 미확인 영향.
