# Delete Pattern

**When:** `catalog/patterns/`의 capsule 원본과 관련 참조를 실제 제거하라는 요청이 있을 때. 검토·은퇴만 필요하면 [Retire](retire.md)를 사용한다.

1. **정확한 원본 경로·ref·승인된 범위**를 확인한다. 알려진 내부·외부 사용, 다른 capsule·문서·README의 참조와 대체 owner를 조사한다. 읽을 수 없는 소비자 상태나 권한을 추측하지 않는다.
2. 삭제하면 사라질 고유한 결정·근거·예시가 있다면 필요한 부분만 적절한 정본으로 이관한다. 중복 기록이나 보관용 복제본을 습관적으로 만들지 않는다.
3. 알려진 링크·탐색 안내·인접 capsule을 조정한다. archive·tombstone·호환 파일은 실질적 필요가 있거나 명시적으로 요청한 경우에만 남긴다.
4. 승인된 범위 안에서만 원본을 제거하고 [Validate](validate.md)로 잔여 참조와 생성 인덱스를 검증한다. 중요 소비 영향·권한이 불확실하면 **차단 또는 부분 인계**하고 삭제 완료라고 주장하지 않는다.

**Result:** 제거된 대상, 이관한 지식, 수정된 참조, 실제 검증 및 남은 위험.
