# Restructure Asset Document

Restructure one asset's content organization without changing its meaning,
behavior, triggers, or safety constraints.

## Execution

1. **Backup**: Execute [backup.md](../backup.md) before edits.
1. **Document Realignment**:
   - Reorder, merge, split, or rename headings and sections.
   - Normalize Markdown formatting and improve document flow.
   - Preserve frontmatter, canonical terms, behavior, triggers, and safety.
1. **Verify Integrity**: Run Markdown validation and inspect the diff for
   unintended semantic changes.
