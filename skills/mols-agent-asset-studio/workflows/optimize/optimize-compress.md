# Compress Asset Workflow

Reduce agent asset token cost while preserving meaning, behavior, and readability.

## Execution

1. **Backup**: Run [backup.md](../backup.md) before making edits.
2. **Preserve Immutables**: Protect frontmatter, code blocks, commands, paths, URLs, and safety constraints.
3. **Prune Redundancy**: Remove filler words, hedging, duplicate rules, and prose repeating tables/code.
4. **Verify Diff**: Confirm token reduction without content/behavior loss.
