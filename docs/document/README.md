# Documentation

이 디렉터리는 **이 repository의 문서 규칙과 관행**을 소유합니다.

## Policies

- [Ownership](ownership.md) — repository와 directory documentation의 책임 경계
- [DRY Boundaries](dry.md) — project docs, references와 asset capsule의 중복 허용 경계
- [Knowledge Lifecycle](knowledge-lifecycle.md) — durable knowledge, inbox, archive와 Git history의 역할
- [Asset Capsules](asset-capsules.md) — `docs/<asset-type>/<asset>/` portable documentation capsule

Repository 개발 규칙과 관행은 [`docs/development/`](../development/)가 소유합니다. 참고용 지식은 [`docs/references/`](../references/)에 둡니다.

이 README는 위 policy의 본문을 복제하지 않는 documentation entrypoint입니다.
