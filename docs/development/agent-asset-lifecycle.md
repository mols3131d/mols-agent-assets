# Agent Asset Lifecycle

이 문서는 **자산 관리의 상태와 작업 종료 기준**을 소유한다. 상황별 실행은 [Agent Asset Workflows](agent-asset-workflows.md), source 배치와 권한은 [Source Authority](source-authority.md)가 소유한다. 다음 상태는 논리적 설명이며 별도 registry·metadata·Issue·CI 단계를 강제하지 않는다.

## 상태와 관리·사용의 분리

| 상태 | 확인할 것 |
| --- | --- |
| 제안·선택 | 신규 자산이 필요한가, 기존 owner나 dependency로 해결 가능한가? |
| 작성·수정 | 어떤 canonical source와 소비자 계약이 바뀌는가? |
| 검토·검증 | 어떤 구조·의미·실제 행동에 대한 근거가 있는가? |
| 제공 가능 | 어떤 route·packaging·revision으로 발견·설치할 수 있는가? |
| 실제 사용 | 어떤 runtime에 실제 설치·선택·적용됐는가? |
| 유지·은퇴 | 무엇을 이전·수정·제거해야 기존 소비자가 안전한가? |

반드시 직선형으로 진행하지 않는다. 같은 자산을 관리하지만 사용하지 않을 수 있으며, 배포 가능해도 실제 설치됐다고 볼 수 없다. `src/`, lock 또는 route의 항목은 그 자체로 실행·설치 증거가 아니다.

## 변경 작업 완료 조건

| 구분 | 종료 판단 |
| --- | --- |
| 정본 | 요청한 범위의 source와 책임·기존 소비 계약이 처리됐다 |
| 문서 | **갱신 / 기존 문서로 충분 / 해당 없음**을 판단했고, 필요한 정본·유지보수 문서를 같은 작업에서 반영했다 |
| 근거 | 변경된 구조·파생·검증·행동의 claim을 실제 확인 수준에 맞춰 제시했다 |
| 인계 | 미해결 위험, 후속 검증 또는 권한 차단을 남겨 재개 경로를 분명히 했다 |

문서 파일을 변경하지 않았다는 이유만으로 실패라 판단하지 않는다. 반대로 새로운 사용법이나 중요 결정이 생겼는데 **문서 영향 판단이 생략됐다면** 완료로 판정하지 않는다. `.inbox/`의 임시 문서는 정본을 대체하지 않는다. 수정 없는 읽기 전용 리뷰·조사는 해당 범위에 맞게 완료 조건을 좁힌다.

## 종료·복구

- **완료:** 요청한 변경, 필요한 문서 반영, 관련 검증·미검증 고지가 이루어졌다. PR Ready와 Merge는 별개 승인·상태다.
- **부분 완료·인계:** 도구/권한/근거의 한계로 남은 범위가 있다면 수행하지 않은 내용을 명시하고 필요한 경우 PR 또는 `.inbox/`에 현재 기준점과 다음 조치를 기록한다.
- **중단·차단:** 잘못된 원본, 권한 불명확, 비가역적 손실 위험이 있는 작업은 임의 우회하지 않는다.
- **은퇴·삭제:** 실제 필요하지 않은 자료는 정리하되, 이전·복구를 위해 필요한 결정만 적절한 정본에 남긴다. 별도 archive는 독립적 가치가 있을 때만 유지한다.

검증 근거의 의미는 [Validation](validation.md), [Testing](testing.md), [Evaluation](evaluation.md)이, GitHub 기록·승인·Merge는 [GitHub](github.md)가 소유한다. 이 문서는 새 실행 권한을 부여하지 않는다.
