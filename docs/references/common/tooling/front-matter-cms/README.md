# Front Matter CMS

이 저장소의 Front Matter CMS configuration authority는 root [`frontmatter.json`](../../../../../frontmatter.json)입니다.

이 reference는 product option catalog를 복제하지 않습니다. 설정을 변경할 때는 current `frontmatter.json`을 먼저 읽고, 필요한 option의 semantics는 official documentation/schema에서 확인합니다.

## Official Sources

- [Documentation](https://frontmatter.codes/docs)
- [Settings](https://frontmatter.codes/docs/settings)
- [Updates](https://frontmatter.codes/updates)
- [Official repository](https://github.com/estruyf/vscode-front-matter)
- [Configuration schema](https://frontmatter.codes/frontmatter.schema.json)

Repository-specific decision이 새로 생기더라도 configuration 자체로 충분히 표현되면 별도 문서로 복제하지 않습니다. Source만으로 복구하기 어려운 durable rationale이 생길 때만 이 문서에 최소한으로 남깁니다.
