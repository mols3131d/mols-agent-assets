# Document Indexing

문서 인덱스는 **탐색에 실제 도움이 될 때만** 둡니다. 사람이 직접 관리하는 별도 index 전용 파일은 만들지 않습니다.

## Principles

| 필요 | 선택 |
| --- | --- |
| 파일명과 검색만으로 충분함 | 별도 index 없음 |
| 사람이 문서의 목적·차이·선택 기준을 함께 봐야 함 | `README.md`의 `Index` section |
| 다시 생성할 수 있는 목록이 필요함 | `INDEX.tsv` |

- README의 `Index`는 사람이 어떤 문서를 볼지 판단하도록 돕는 작은 탐색 목록입니다.
- `INDEX.tsv`는 도구로 다시 만들 수 있는 목록입니다.
- 둘을 함께 사용하더라도 같은 정보를 반복하지 않습니다.
- Index는 원본 문서나 정본을 대신하지 않습니다.
