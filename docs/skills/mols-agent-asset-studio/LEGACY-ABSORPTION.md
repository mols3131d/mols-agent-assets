# Legacy Knowledge Absorption — v2.1

The legacy Studio was not restored as a router. Its remaining valuable operating
knowledge was absorbed into the modern lifecycle.

| Legacy knowledge | v2.1 implementation |
| --- | --- |
| Skill consolidation and routerization boundaries | `consolidate` mode, `consolidation.md`, analyzer, plan and route-case templates |
| Compression invariants | `semantic-preservation.md`, invariant template and checker |
| Empty directories, nested skills, unused scaffolding | structural validator and audit command |
| Idempotent generated index principle | byte-reproducible skill and bundle ZIP writers |
| Domain and complexity naming heuristics | project-first `naming.md` fallback |
| Scriptification feasibility and ROI | `determinism.md` decision matrix |
| Backup intent without permanent `.tmp` accumulation | conditional Git-first rollback contract |
| Reuse of project Markdown and CI tools | validated profile commands and argv-only host runner |

## Deliberately Not Restored

- mandatory CSV routing for a small workflow set
- permanent backup accumulation
- ceremonial evaluate, plan, and apply micro-workflows
- keyword-only routing
- universal runtime-field matrices
- unconditional approval questions

The result preserves useful operational discipline without restoring legacy
indirection or unsafe defaults.
