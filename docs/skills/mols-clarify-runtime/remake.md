# Remake Recommendation

현재 실행 근거로 중요한 동작을 복원하는 문제에 집중한다. 기존 evidence 우선, 필요할 때만 최소 안전 scenario 실행, 반복적인 복원 필요성이 있을 때만 evidence 유지라는 계약을 보존한다. 디버깅·instrumentation과의 책임 경계 및 단계·옵션·reference 비용을 재검토한다.

권고 상태이며 현재 실행 계약은 변경하지 않는다.
