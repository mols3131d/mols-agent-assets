# Remake Recommendation

관계·방향·상태·순서·경계의 의미 보존에 집중한다. Mermaid chart와 공통으로 사용하는 type 선택, 편집·검증 지침을 중복하지 않도록 단일 진입점 및 조건부 diagram reference를 검토한다. 분리 여부는 실제 routing·loading 비용과 독립 사용 가치에 근거한다.

권고 상태이며 현재 실행 계약은 변경하지 않는다.
