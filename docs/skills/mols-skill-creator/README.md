# mols-skill-creator Maintainer Docs

이 디렉터리는 `mols-skill-creator`의 portable maintainer documentation capsule입니다.

1. 핵심 목적·요구사항·불변조건을 확인하거나 변경하려면 [`baseline/DIRECTIVE.md`](baseline/DIRECTIVE.md)를 먼저 읽습니다.
1. 현재 유지보수 상태와 구조를 파악하려면 [`WORKING.md`](WORKING.md)를 읽습니다.

Runtime 동작은 대응 asset package가 소유합니다. 이 capsule은 asset과 함께 다른 host repository로 이동해도 maintainer intent와 recovery context를 유지하기 위한 non-runtime surface입니다.
