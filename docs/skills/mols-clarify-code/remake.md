# Remake Recommendation

소스 내부 설명이 필요한 durable meaning(호출 계약, 비자명한 제약·불변식·실패 의미)에 집중한다. 일반 구현 지침과 중복되는 절차 및 argument surface를 축소할 수 있는지 확인한다. 실행 코드 변경 없이 필요한 설명을 보강하고 machine-consumed documentation의 계약을 보존하는 경계는 유지한다.

권고 상태이며 현재 실행 계약은 변경하지 않는다.
