# Remake Recommendation

명시적 변증법 요청에서 강한 반대 논거를 검토하고 근거에 따라 결론을 개선하는 책임은 보존한다. 현재 세 specialist에 대한 실행 의존성과 순서 제어가 실제로 독립 검토 품질을 높이는지 확인하고, 독립 실행이 불가능한 환경에서의 과도한 의존성과 비용을 줄인다. 독립성이 관찰되지 않으면 주장하지 않는다.

권고 상태이며 현재 실행 계약은 변경하지 않는다.
