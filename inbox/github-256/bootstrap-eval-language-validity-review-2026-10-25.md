# 한국어와 평가 타당성 검토

**기존 실패를 작은 모델의 능력 한계나 Skill 단독 결함으로 단정할 수 없다.** 사용자가 한국어 지원 전제를 지적해 공식 자료와 로컬 모델 metadata를 확인했다. 이전 12-case 결과는 해당 조합의 관찰값이며 원인 분리 실험이 아니다.

## 확인한 사실 — 2026-10-25

| 평가 모델 | 공식 근거 | 해석 |
| --- | --- | --- |
| `nemotron-3-nano:4b` | [NVIDIA의 4B 모델 카드](https://huggingface.co/nvidia/NVIDIA-Nemotron-3-Nano-4B-BF16)는 지원·사용 언어를 영어로 명시한다. 학습 데이터 설명에는 한국어가 포함된다. | 한국어 학습 포함을 한국어 복합 지시 이행의 지원·품질 보장으로 해석할 수 없다. 한국어 Skill의 대표 평가 모델 적합성은 미확인이다. |
| `qwen2.5-coder:7b` | [Qwen2.5 발표](https://qwenlm.github.io/blog/qwen2.5/)는 일반 언어 모델의 한국어 지원을 명시하지만 [Coder 7B 모델 카드](https://huggingface.co/Qwen/Qwen2.5-Coder-7B-Instruct)는 해당 변형의 한국어 품질 근거를 별도로 제시하지 않는다. | 일반 계열의 지원 설명만으로 양자화된 Coder 7B의 한국어 정책·채점 적합성을 확정하지 않는다. 한국어 불가라는 뜻도 아니다. |

로컬 `/api/show`에서 Qwen은 `Qwen2.5-Coder`·`Instruct`·7.6B, Nemotron은 `nemotron_h`·4.0B이며 두 모델 모두 Q4_K_M임을 확인했다. 두 metadata에 언어 목록은 없었다. 모델 변경·다운로드·새 inference는 하지 않았다. 현재 Ollama 페이지의 여러 크기를 묶은 소개보다 정확한 4B 원제작자 모델 카드를 우선한다.

## 기존 결론의 수정

- Skill과 대부분의 요청은 한국어이고 rubric·보정 정상 응답은 영어다. 한국어/영어 동등 입력 비교나 Skill 없음/있음 비교를 하지 않았다. 언어·Skill·모델·runtime·grader의 영향을 분리하지 못했다.
- 원문에서 관찰한 누락과 고정 표본의 채점 불일치는 남지만, 그 원인이 모델 크기라고 입증된 것은 아니다. 기존 결과의 “작은 모델의 한계”는 관찰 조건을 넘어선 인과 설명으로 사용하지 않는다.
- Skill에는 여러 경계·예외가 한 문장에 모인 규칙이 있고 각 assertion도 복수 요구를 묶는다. 지시의 우선순위·출력 구조, 요청과 평가 기준의 정합성은 검토할 가설이다. 아직 Skill 결함이 주원인이라는 확정 근거는 아니다.
- 사례 전 기준 충족 0/6은 모든 응답이 무가치하거나 모든 기준이 실패했다는 뜻이 아니다. 두 모델 모두 원문 검토에서 18기준 중 7개를 충족했다.

## 최소한의 다음 비교

대표 실패 2~3건에서 의미·기준을 고정해 **한국어/영어 × Skill 없음/있음**을 같은 모델·runtime 설정으로 비교한다. Target 언어 효과와 grader 언어 효과는 분리하며, 알려진 자동 grader 오판 때문에 원문 판정도 함께 둔다. 이 비교는 아직 실행하지 않았다. 특정 원인을 확정하기 전 한국어 사용 환경에 적합한 평가 모델인지부터 확인한다.

이 검토는 [기존 실행 결과](bootstrap-eval-improvement-results-2026-10-25.md)의 수치를 바꾸지 않고 해석 범위를 정정한다. Canonical Skill 번역·재작성이나 새 모델 도입을 결정한 것은 아니다.
